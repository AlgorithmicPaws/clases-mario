# Insumos — Práctica del Módulo 7

Materiales para la práctica de cierre del curso. Esta práctica es distinta a las anteriores: no
busca producir un entregable, sino **entrenar el ojo crítico**. Varios ejercicios están diseñados
para que la IA **falle delante de ti** — ese es justamente el aprendizaje.

| Insumo | Ejercicio | Para qué |
|--------|-----------|----------|
| [`01-respuestas-sospechosas.md`](01-respuestas-sospechosas.md) | 1 · Cazar el error plausible | Cinco respuestas de IA, algunas con errores sutiles. Entrenar la detección. |
| [`02-prompt-con-datos-sensibles.md`](02-prompt-con-datos-sensibles.md) | 4 · Limpiar un prompt | Un prompt real cargado de datos que no deberían salir. Practicar anonimización. |
| [`03-plan-personal.md`](03-plan-personal.md) | 5 · Plan de 90 días | Plantilla de cierre: qué caso adoptar, qué fuentes seguir, qué reglas fijarte. |

**Ejercicios sin insumo (se hacen en vivo con Claude):**
- **Ejercicio 2 · Test de la complacencia:** necesitas una pregunta con respuesta objetiva que
  **tú sepas**. El valor está en llevarle la contraria y ver si cede.
- **Ejercicio 3 · Abogado del diablo:** usa una idea o plan **real** tuyo (puedes reusar el del
  Módulo 4).

## Cómo usarlos

1. Abre la slide del ejercicio en la presentación del Módulo 7.
2. Haz el ejercicio **antes** de leer las soluciones o comentar en grupo: el aprendizaje está en
   equivocarse primero.
3. Comenta en grupo qué detectaste y qué se te pasó.

> El insumo `01` contiene errores **a propósito**. No lo uses como material de referencia: sus
> datos son incorrectos por diseño.
