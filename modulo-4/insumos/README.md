# Insumos — Ejercicios del Módulo 4

Materiales para llevar a cabo la práctica guiada del Módulo 4. A diferencia de módulos
anteriores, aquí el hilo es **un solo proyecto que se construye a lo largo de los cinco
ejercicios**: preparar la propuesta de impresión para el cliente **Andes Verde**. Así se
siente el método completo (specdoc → iteración → verificación → continuidad → criterio) sobre
un caso continuo, en el contexto de **Imprenta Castro & MacDonald**.

| # | Ejercicio (slide) | Insumo | Para qué |
|---|-------------------|--------|----------|
| 1 | Escribir un specdoc | [`01-pedido-andes-verde.md`](01-pedido-andes-verde.md) | El encargo del cliente + contexto de la imprenta. Practicar el specdoc con vs. sin plano. |
| 2 | El ciclo iterativo | (usa el borrador del Ej. 1) | Iterar el borrador con feedback vago vs. concreto. |
| 3 | Verificar, no solo confiar | [`02-tarifas-y-margenes.md`](02-tarifas-y-margenes.md) | Costos, IVA y margen mínimo para comprobar la aritmética con ejecución de código. |
| 4 | Continuidad entre sesiones | [`03-documento-estado-plantilla.md`](03-documento-estado-plantilla.md) | Plantilla de documento de estado para hacer el handoff entre dos "días". |
| 5 | Cazar la deuda | (usa cualquier entregable del día) | Aplicar la prueba de la defensa sobre algo aceptado sin entender. |

## Cómo usarlos

1. Abre la slide del ejercicio en la presentación del Módulo 4.
2. Abre el insumo correspondiente y pega (o adjunta) el bloque que indica.
3. Sigue los pasos de la slide: primero el intento "sin método", luego el dirigido.
4. Compara resultados y comenta en grupo.

> Los datos (precios, gramajes, plazos, márgenes) son **realistas pero de ejemplo**: sirven para
> el ejercicio, no son tarifas oficiales.
