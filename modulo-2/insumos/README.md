# Insumos — Ejercicios del Módulo 2

Materiales para llevar a cabo los cinco ejercicios prácticos del Módulo 2. Cada archivo es el
**material de entrada** que pegas (o adjuntas) al modelo durante el ejercicio. Están pensados
para el contexto real de **Imprenta Castro & MacDonald**.

| # | Ejercicio (slide) | Insumo | Para qué |
|---|-------------------|--------|----------|
| 1 | El manual de 80 páginas del cliente | [`01-manual-cliente.md`](01-manual-cliente.md) | Documento largo con un dato concreto "enterrado". Practicar *documento arriba / pregunta abajo* y pedir la cita. |
| 2 | Responder a una editorial que pide bajar costos | [`02-correo-editorial.md`](02-correo-editorial.md) | Correo entrante + cotización original. Practicar prompt vago vs. dirigido (rol, "por qué", formato). |
| 3 | Clasificar los correos de pedidos | [`03-correos-pedidos.md`](03-correos-pedidos.md) | Lote de correos reales para clasificar + ejemplos para el few-shot. |
| 5 | La disculpa por una diferencia de color | [`05-reclamo-color.md`](05-reclamo-color.md) | Reclamo del cliente + notas técnicas para verificar la respuesta. |

## Cómo usarlos

1. Abre la slide del ejercicio en la presentación del Módulo 2.
2. Abre el insumo correspondiente y copia el bloque que indica cada archivo.
3. Sigue los pasos de la slide (primero el intento "ingenuo", luego el dirigido).
4. Compara resultados y comenta en grupo.

> Los datos (precios, gramajes, plazos) son **realistas pero de ejemplo**: sirven para el
> ejercicio, no son tarifas oficiales.
