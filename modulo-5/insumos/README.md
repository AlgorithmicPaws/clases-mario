# Insumos — Práctica del Módulo 5

Materiales para probar en vivo los casos de la galería. No hace falta usarlos todos: en la
segunda hora se eligen cuatro o cinco casos. Cada archivo es el **material de entrada** que
pegas o adjuntas al modelo.

| Insumo | Caso | Para qué |
|--------|------|----------|
| [`01-ventas.csv`](01-ventas.csv) | A1 · Excel de ventas | Datos de ventas para analizar con ejecución de código y graficar. |
| [`02-contrato-extracto.md`](02-contrato-extracto.md) | A3 · Contrato | Extracto de contrato para resumir con riesgos y citas. |
| [`03-anuncio-precios.md`](03-anuncio-precios.md) | B3 · Tres tonos | Situación para redactar el mismo mensaje en tres registros. |
| [`04-idea-vaga.md`](04-idea-vaga.md) | D1 · Idea → plan | Idea difusa para convertir en un plan por fases. |

**Casos sin insumo (usa material propio o el prompt de la ficha):**
- **A2 · Factura:** usa la **foto de un recibo real** tuyo (o una captura). El valor está en
  probarlo con algo del mundo real.
- **A4 · Reunión/video:** usa la transcripción de una reunión propia o el **enlace a un video**
  de YouTube largo.
- **B1 · Mini-app:** solo necesitas el prompt de la ficha B1.
- **B2 · Imágenes:** solo necesitas una descripción; no requiere archivo.
- **C1 · Correo/agenda:** requiere un **connector activo** (correo o calendario). Si no hay, se
  explica sobre papel.
- **C2 · Investigación:** usa un tema actual real; el valor está en abrir las fuentes citadas.

## Cómo usarlos

1. Abre la ficha del caso en la presentación o la wiki del Módulo 5.
2. Adjunta o pega el insumo indicado.
3. Usa el prompt de ejemplo de la ficha (adáptalo a tu contexto).
4. Aplica siempre el **"Ojo"** del caso: verifica antes de confiar.

> Los datos (ventas, cláusulas, precios) son **realistas pero de ejemplo**: sirven para la
> práctica, no son información oficial.
